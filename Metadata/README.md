# Metadata

Registries and generated indexes — the vault's own bookkeeping, not vault content.

| File / dir | What |
|---|---|
| `area_registry.md` | The list of valid area slugs. Human-maintained; Cursor never adds a new one on its own. |
| `tag_registry.md`, `topic_registry.md` | Canonical tag/topic vocabularies, same rule. |
| `entity_registry.md` | Canonical people/company/product names + transcript mis-hearings. `## Canonical` is triage-approved only; summarize/distill append to `## Proposed`. |
| `recap/<area>/YYYY-MM.md` | Triage session logs, one append per session. |
| `review/YYYY-Www.md` | Weekly objectives-review logs. |
| `index.md` (if present) | Generated by `scripts/build_index.py` — never hand-edit; it's overwritten on the next rebuild. |
| `User.md` | Generated from `.env`'s `LEXICON_USER_NAME` by `lexicon_init.py` — never hand-edit. |

**No hand-maintained maps.** If a file here looks like an index of other files, it's generated — check the script that owns it before editing by hand.
