# Memory

**Descriptive tier: what is true.** Distilled, synthesized knowledge — not raw meeting notes, not intentions.

- `Memory/<area>/*.evidence.md` — append-only dated bullets, one line each, written by distill.
- `Memory/<area>/*.md` (everything else) — `# Current model`, synthesis, updated only in triage with your approval.

**Written by:** distill (evidence files only), triage (current-model files, with your approval each time).

**Read by:** every query about "what do we know / what's true about X."

**What does NOT belong here:**
- Purpose, principles, standards for an area → `Direction/<area>.md` (normative, not descriptive — see [docs/OBJECTIVES.md](../docs/OBJECTIVES.md))
- Horizon-bound intentions → `Objectives.md`
- The raw meeting or transcript → `Meetings/`, `Transcripts/`

See [docs/MEMORY_MODEL.md](../docs/MEMORY_MODEL.md) for the full evidence/current-model split and the two supported layouts.
