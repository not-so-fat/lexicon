# People

One profile per person: `People/<area>/<Name>.md`.

```
# Current read        (~5 bullets, refreshed in triage)
# Evidence Log         (append-only, written by distill)
```

**Written by:** distill (Evidence Log), triage (Current read, with your approval).

**Read by:** "who is X," meeting prep, anything needing context on a person before a conversation.

**What does NOT belong here:** organizational or process knowledge about an area — that's `Memory/<area>/Org.md` or similar. This directory is people, not areas.
